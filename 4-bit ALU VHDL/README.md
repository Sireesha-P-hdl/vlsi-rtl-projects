4-Bit ALU in Verilog
This project implements a 4-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs basic arithmetic and logical operations on two 4-bit inputs based on select lines, making it a simple but strong digital design project for learning combinational logic, RTL design, and simulation workflow.

Project Overview
The design supports multiple operations such as:

Addition

Subtraction

Comparison

Bitwise AND

The project includes the main Verilog design, testbench files, and simulation output for verification. It is suitable for students who want to understand how an ALU works at the hardware level and how to verify it using digital simulation tools.

What I learned from this project
Writing combinational logic in Verilog.

Using select signals to control ALU operations.

Creating and running testbenches.

Verifying outputs using waveform simulation.

Understanding arithmetic and logic circuit behavior.
